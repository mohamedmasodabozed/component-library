# Component Library

A reusable React component library for building consistent user interfaces.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes with Node.js)

### Installation

```bash
npm install
```

### Development

Start the local development environment:

```bash
npm run dev
```

### Build

Create a production build of the component library:

```bash
npm run build
```

### Test

Run the test suite:

```bash
npm test
```

## Usage

Import components from the library in your React app:

```jsx
import { Button } from 'component-library';
```

## Contributing

1. Create a branch for your change.
2. Make your updates.
3. Run build and tests.
4. Open a pull request.
